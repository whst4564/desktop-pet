# 验证范围

更新日期：2026-10-28。

本仓库提供整理后的源码和资源，没有附带已签名的发行程序。源码中的个人数据目录回退已改为通用的 `CODEX_HOME` / `%USERPROFILE%/.codex`，因此本仓库构建与开发时的原始二进制不是同一个文件。

| 项目 | 已有验证及限制 |
| --- | --- |
| 对话读取 | 26 项合成检查通过；原候选程序曾成功读取当前聊天的近期消息；不发布实际聊天或会话编号 |
| App Server 连接 | HTTP 调整前 28 项模拟 stdio 检查通过；调整后 32 项测试已编译，运行曾被开发机应用程序控制阻止，未宣称通过 |
| 真实模型 | 独立的官方 CLI 使用 HTTPS/SSE 完成一次简短模型回复；不等于最终桌宠程序端到端验收通过 |
| 去除混帧重影 | 较早候选程序实际 WPF 导出核对 105 个采样位置，保持原始素材像素；不证明所有设备的桌面合成拖影均已消除 |
| 拖动与思考 | 候选绘制检查覆盖四组共 1056 帧惯性、64 帧目光、128 帧思考；物理桌面交互与白条联动仍需实机验收 |

开发机曾出现 Windows Code Integrity 签名要求导致新版 EXE 无法启动。本仓库不提供关闭保护、绕过签名检查或由其他宿主加载被拦截程序的方法。适用的签名、分发方式和最终运行验证仍待完成。

`tests/` 中的示例字符串、假模型名和假认证错误均为测试夹具，不是实际凭证。默认构建只编译和复制资源，不运行测试、发送消息或调用模型。
